**الإصدار 1.1 — إصلاح المحتوى والصور داخل المشروع الحالي.** اقرأ [تقرير الإصلاح واختبارات المصادر](docs/CONTENT_IMAGES_1_1.md). التحديث يحافظ على معرّفات الأخبار والتدوينات والتحليلات والمفاتيح. يدعم Room v2 ترحيل قاعدة الإصدار السابق دون مسحها.

يُفصل وصف RSS عن محتوى الناشر الكامل. عند عدم توفره يظهر تنبيه مقتطف وزر «قراءة الخبر كاملًا» في Chrome Custom Tabs. صور الأخبار من RSS أو صفحة المقال المرتبطة فقط، وتُعرض عبر Coil. استخراج صفحة المصدر يحتاج إذنًا مسجلًا ومراجعة robots.txt؛ الافتراضي لا يفترض السماح لكل موقع.

تطبيق Android Native شخصي بالعربية وRTL، مبني من الصفر باستخدام Kotlin وJetpack Compose وMaterial 3، بهوية داكنة مستوحاة من المرجع المرفق. لا يحتاج حسابًا سحابيًا أو خادمًا وسيطًا. **لا يحتوي مفاتيح API**.

## التثبيت والاستخدام

1. انقل `Nabd-personal.apk` إلى هاتف Android 8 أو أحدث وثبّته، بعد السماح بالتثبيت من تطبيق الملفات إذا طلب Android ذلك. النسخة المسلّمة APK شخصي موقّع بتوقيع Debug وليست نسخة متجر.
2. افتح **الإعدادات ← OpenAI API**، أدخل المفتاح واضغط **حفظ المفتاح**.
3. اضغط **اختبار الاتصال وتحديث النماذج**، ثم اختر نموذج نصوص يدعم Responses API. اختبار الاتصال يختبر المصادقة وقائمة النماذج؛ أول تلخيص يختبر التوليد الفعلي.
4. يمكنك تخصيص نموذج مختلف لكل مهمة. يصبح OpenAI الافتراضي عند وجود مفتاحه ما لم تختر غير ذلك.
5. من الرئيسية اضغط التحديث لقراءة RSS. يمكنك إدارة المصادر من الإعدادات وإضافة خلاصة HTTPS أو مادة يدويًا.
6. افتح الخبر ← **مساعد نبض الذكي** ← اختر المهمة والمحرك ← راجع الإرسال ثم نفّذه. تُحفظ النتائج تلقائيًا في السجل.
7. من النتيجة اختر **حفظ في الدفتر**. افتح دفتر نبض لتحرير التدوينة ووسومها وتثبيتها وتصديرها.
8. افتح **محادثة حول هذا الخبر** لحوار مستقل محفوظ. أحدث جزء فقط من الحوار يُرسل ضمن حد سياق محلي، وليس كامل الأرشيف.

لا ترسل المفتاح في محادثات أو ملفات دعم، ولا تضفه إلى Git أو Gradle. أدخله في الهاتف فقط.

## ما يتضمنه المشروع

- RSS وAtom عند الطلب، مصادر قابلة للإضافة والحذف، حفظ أخبار ومنع تكرار الرابط.
- إضافة خبر أو منشور X يدويًا وفتح حسابات X خارجيًا، دون API مدفوع أو تجاوز لقيود X.
- طبقة `AiProvider` مستقلة وOpenAI Responses API وGemini generateContent عبر HTTPS وRetrofit/OkHttp، بلا خادم وسيط وبلا انتقال آلي بين النماذج.
- حفظ مفاتيح AES-GCM بمفاتيح غير قابلة للتصدير في Android Keystore. منع النسخ التلقائي والنقل، وFLAG_SECURE على النوافذ.
- تلخيص بمستويات متعددة، معلومات وأرقام، تحليل، فحص ادعاءات، مقارنة أخبار وأسئلة مخصصة.
- بحث ويب اختياري عبر أداة OpenAI الرسمية عند دعم النموذج؛ استخراج روابط annotations الفعلية. دونها يبقى الفحص «أدلة غير كافية — تحليل للمعلومات المتاحة».
- محادثة لكل خبر وسياق محدود، نسخ الإجابات وحفظها في الدفتر.
- دفتر محلي، مسودات محفوظة تلقائيًا بعد توقف الكتابة وعند مغادرة الشاشة، Markdown للعناوين والقوائم والنص البارز، روابط ووسوم وتصنيفات وتثبيت وحذف.
- سجل التحليلات، تخزين وإعادة استخدام النتائج المطابقة، بحث شامل محلي وتصفية الأخبار ومحتوى مرتبط بحسب التاريخ والمصدر والتصنيف.
- تصدير دفتر Markdown ونسخة محتوى JSON واستعادة مدمجة بمعرّفات ثابتة. **ملف التصدير مقروء وقد يحتوي ملاحظاتك الخاصة؛ لا يتضمن مفاتيحك أو إعداداتك أو سجل ميزانيتك**.
- عداد محلي للطلبات وTokens حيث تتوفر، وتسعير قابل للإدخال لكل نموذج، وميزانية OpenAI يومية وشهرية مع حجز تقديري محافظ ومنع الطلب عند غياب بيانات الكلفة مع حد مفعّل.
- ML Kit GenAI حقيقي لفحص Nano وتنزيله وتجربة تلخيص محلي، وليس محركًا وهميًا.
- مخططا Room v1 وv2 مُصدّران، مع MIGRATION_1_2 يحافظ على البيانات واختبار SQL فعلي يقارن المخطط بعد الترحيل بمخطط Room الجديد، ودون destructive migration.
- GitHub Actions للبناء وLint واختبارات JVM واختبارات محاكي Android 35؛ لا تحتاج أسرار API.

## حدود مهمة وشفافة

- مفتاح الهاتف المشفّر لا يملك أمان خادم وسيط. فصل `AiProvider` يسمح باستبدال المسار بوسيط لاحقًا.
- الاتصال بالسحابة يرسل النص المعروض/المحدد إلى المزود. الملاحظات لا تُرسل إلا باختيار مربع الإذن الصريح ومراجعة الإرسال.
- محتوى الأخبار هو النص المنشور في الخلاصة أو النص المسموح استخراجه من صفحة المقال أو النص الذي أضفته؛ وقد يكون مقتطفًا. لا يُجلب المقال المحمي أو يُتجاوز اشتراك.
- مصادقة المفتاح لا تضمن صلاحية كل نموذج؛ يعرض التطبيق أخطاء النموذج أو الحصة دون تبديل تلقائي.
- **لا يستطيع مفتاح Gemini إثبات فئة الحساب أو عداد حصته المجانية عبر API موثوق.** يجب مراجعة لوحة Google وتأكيد اختيار الفئة المجانية لكل نموذج، بما فيه النموذج المخصص للمهمة. لا يمكن للتطبيق إلغاء فوترة مفعّلة عند Google؛ تحقق من حسابك. لا يُغيّر التطبيق النموذج أو ينتقل لخدمة مدفوعة تلقائيًا.
- مكتبة Nano المدمجة `genai-summarization:1.0.0-beta1` تدعم رسميًا الإنجليزية واليابانية والكورية. العربية تجربة غير مضمونة، وقد يرفضها المحرك. اسم Galaxy S26 Ultra لا يضمن AICore أو توفر النموذج. لا يوجد fallback سحابي صامت.
- لا توفر X قراءة مجانية عامة مضمونة لكل الحسابات؛ المتابعة هنا فتح خارجي، استيراد نص يدوي، أو RSS مصرح به. لا يوجد سحب آلي للحسابات.
- فحص الذكاء الاصطناعي ليس حكمًا نهائيًا بصحة خبر. حتى الاستشهادات الخارجية تُعرض للمراجعة البشرية، ولا تُختلق علامة «صحيح» تلقائية.
- الميزانية والتكلفة تقدير محلي، لا رصيد OpenAI الفعلي. رسوم الأدوات وخصومات cache والفوترة الخارجية ليست محسوبة؛ البحث الخارجي ممنوع عند تفعيل ميزانية محلية. الطلب المقطوع قد يكون احتُسب، فيُعلّم للمراجعة ويمنع متابعة الميزانية حتى تسويته يدويًا من لوحة المزود.
- البحث المحلي مناسب للأرشيف الشخصي ويستخدم قوائم Room المرصودة؛ للأرشيف الضخم يُوصى بإضافة FTS وترقيم صفحات لاحقًا.
- كيان المرفقات موجود للتوسعة؛ لا يتضمن هذا الإصدار محرر ملفات مرفقة. تُصدّر النصوص والروابط فقط.
- لم يُرفع المشروع إلى GitHub ولم تُشغّل Actions عن بُعد، لعدم تحديد مستودع. ملف سير العمل جاهز.

## البناء

متطلبات: Android Studio حديث، JDK 17 أو 21، Android SDK Platform 35 وBuild Tools 35.0.0. افتح مجلد المشروع في Android Studio ودع Gradle يجلب الاعتماديات. قد يطلب Gradle قبول تراخيص SDK.

```bash
python3 scripts/fetch_reference_fixtures.py
./gradlew testDebugUnitTest lintDebug assembleDebug assembleDebugAndroidTest
# يتطلب جهازًا أو محاكيًا متصلًا:
./gradlew connectedDebugAndroidTest
```

الـ APK: `app/build/outputs/apk/debug/app-debug.apk`.
تقارير الاختبار: `app/build/reports/`. المخطط: `app/schemas/`.

لا تُضف `local.properties` أو مفاتيح أو keystore إلى Git. البناء محليًا لا يتطلب مفتاح OpenAI أو Gemini. الاختبارات تستخدم placeholders وMockWebServer وMockAiProvider.

## بنية التطبيق

`MainActivity` وواجهات Compose → `NabdViewModel` → مستودعات الأخبار وAI والنسخ → Room / `AiProvider` / `SecureSettings`.

- `Database.kt`: كيانات DAO وRoom وFlow.
- `SecureSettings.kt`: الخزنة المشفرة والإعدادات غير السرية.
- `AiProvider.kt`: نماذج الطلب والاستجابة والمزودان وأخطاء آمنة.
- `AiRepository.kt`: السياق والتخزين المؤقت ومراجعة التكلفة والتنفيذ المتسلسل.
- `NanoEngine.kt`: ML Kit المحلي بلا انتقال إلى السحابة.
- `NewsRepository.kt`: قراءة RSS/Atom وتنظيف HTML دون تنفيذ النصوص.
- `BackupRepository.kt`: تصدير واستعادة المحتوى داخل معاملة Room.
