# تشغيل اختبار BBC على Samsung Galaxy

الحزمة com.nabd.news.bbcdiagnostic مستقلة عن com.nabd.news. لا تحذف نبض الأصلي؛ لا يلزم تغييره أو إدخال مفاتيح API. حزمة الاختبار لا تفتح قاعدة أخبار نبض أو تعدلها.

## التثبيت والتشغيل

1. نزّل Nabd-BBC-diagnostic.apk وافتحه من «ملفاتي» ← «التنزيلات» على الجالكسي. إذا نزّلته على الكمبيوتر، انقله إلى الهاتف أولًا.
2. إذا طلب Android إذن التثبيت من المصدر الذي فتحت منه الملف، امنح الإذن وأكمل التثبيت.
3. افتح الأيقونة «نبض • اختبار BBC»؛ لا تفتح نبض الأصلي لهذا الاختبار.
4. لاختبار بيانات الهاتف تحديدًا، أوقف Wi-Fi وشغّل بيانات الجوال. الأداة تستخدم مسار شبكة Android المعتاد؛ لا يوجد Proxy خاص ببيئة Codex داخلها. إذا كان الهاتف يستخدم VPN أو Proxy على مستوى النظام، فسيتبع إعدادات جهازك المعتادة.
5. اضغط «بدء اختبار الرابط عبر اتصال الهاتف». لا توجد نتيجة مفترضة أو تشغيل تلقائي عند فتح التطبيق.
6. انتظر اكتمال المحاولات وظهور الحالة. كل طلب له مهلة 35 ثانية؛ قد يصل الانتظار إلى نحو دقيقتين عند تعذر بعض الطلبات.
7. اضغط «حفظ حزمة التقرير وHTML المتاح»، واختر مجلد Downloads/التنزيلات ثم «حفظ» في نافذة Android.
8. انتظر رسالة «حُفظ التقرير»، ثم افتح «ملفاتي» وابحث عن bbc-c6ly0gdxd5jlo-diagnostic.zip. اضغط مطولًا عليه واختر «مشاركة»، أو أرفقه هنا لتحليل النتيجة.

## محتوى ZIP

- report.json: الحالات والأرقام ونتائج النقل والتحليل.
- report-ar.md: تقرير قابل للقراءة.
- bbc-article-response.html: يوجد فقط إذا وصل HTML وسمحت فحوص الوصول بحفظه للتحليل.

فشل طلب BBC لا يمنع حفظ تقرير الخطأ في ZIP؛ غياب ملف HTML لا يعني أن المقال فارغ. حقلا المقارنة مع RSS قد يبقيان غير معروفين إذا خرج الخبر من الخلاصة الحالية؛ يمكن لصق وصف RSS الأصلي المحفوظ في الحقل الاختياري، ويُميز بأنه مدخل يدوي.

لم يُختبر تشغيل الزرين فعليًا على هاتف متصل في هذه الجلسة. روجع الكود، وبُنيت الحزمة وفُحص توقيعها ومعرّفها. لا يُعد ذلك نجاحًا لاستخراج المقال أو اختبارًا لمنطقة شبكة هاتفك. كود محرك الأخبار الإنتاجي لم يتغير.

## بديل التنزيل عبر GitHub Actions

المشروع المرفق يحتوي .github/workflows/bbc-diagnostic.yml. بعد وجود المشروع كاملًا في مستودعك:

1. افتح Actions ← Build BBC diagnostic APK.
2. اختر Run workflow ثم انتظر اكتمال البناء.
3. افتح التشغيل الناجح، ثم Artifacts ← Nabd-BBC-diagnostic.
4. نزّل الأرشيف وفكّه؛ ثبّت Nabd-BBC-diagnostic.apk فقط. ملف tests.apk مخصص لاختبار USB الآلي، وليس مطلوبًا للتشغيل اليدوي.

البناء لا ينفذ طلب المقال ولا يعلن نجاح استخراجه؛ الاتصال الفعلي يبدأ من هاتفك بعد الضغط على الزر. workflow جاهز محليًا، ولم يُرفع أو يُشغّل على GitHub لعدم وجود مستودع Nabd مرتبط بهذه الجلسة. ملفات APK التشخيصية للتوزيع اليدوي موقعة Debug؛ بناء Actions مستقل قد يستخدم توقيع Debug مختلفًا عن الحزمة المحلية. هذا يخص حزمة التشخيص وحدها ولا يغير نبض الأصلي.
