# نبض 1.1 — إصلاح المحتوى والصور

تم تعديل المشروع القائم في `/workspace/Nabd` دون إعادة إنشائه أو حذف وظائف الأخبار والدفتر والمحادثات والتحليلات. التطبيق ما زال `com.nabd.news`، وversionCode أصبح 2، وRoom أصبح v2 بترحيل صريح من v1.

## السبب الجذري

كان المحلل يجمع `description` و`summary` و`content:encoded` في `body` واحد بحسب طول النص، ثم يحوّل HTML إلى نص مسطح. بذلك ضاعت دلالة «مقتطف» مقابل «محتوى الناشر» والفقرات والصور. لم تكن هناك مرحلة لجلب صفحة المقال، ولم تُملأ صور RSS أو بيانات الصور الوصفية. الواجهة لم تتضمن Coil أو صورًا داخل متن المقال.

## التغيير الوظيفي

- يحتفظ `Article` بالعنوان والرابط الأصلي واسم المصدر وتاريخ النشر، ويفصل `summary` عن `fullContent` و`contentBlocks` و`images` والصورة الرئيسية. `body` باقٍ للتوافق مع البيانات السابقة؛ ليس معيار اكتمال المقال.
- `sourceId` يربط الخبر بالمصدر بدقة، و`sourceItemId` يحفظ RSS GUID أو Atom ID. الدمج يستخدم الرابط الموحّد ومعرّف الناشر، مع حفظ معرّف الخبر والتثبيت والمحـفوظات والتصنيف السابق والوصف القديم إذا أغفلته الخلاصة الجديدة.
- يفهم المحلل RSS وAtom وXHTML وCDATA ومساحات الأسماء البديلة، ويحترم ترميز XML. `content:encoded` أو Atom `content` لهما دلالة مستقلة عن طول الوصف، حتى لو كرر الناشر النص في الحقلين. مؤشرات البتر الصريحة تبقي المحتوى مقتطفًا.
- الأخبار القديمة تُرحّل كمقتطفات بأمان. عند فتح خبر قديم يُفحص RSS الأصلي مرة لكل مصدر ضمن مهلة محلية لاستعادة التنسيق والصور إذا بقي الخبر في الخلاصة. إن لم يعد متاحًا، يبقى نصه ورابطه ولا يُختلق له محتوى.
- إذا لم يتوفر محتوى ناشر في RSS، يمكن جلب صفحة المقال **فقط بعد تسجيل إذن المصدر ورابط شروطه من «مصادر الأخبار ← إعداد استخراج المقال»**، وبعد فحص robots.txt. تظل المصادر غير المعروفة على RSS وفتح الأصل افتراضيًا؛ عدم المنع في robots ليس ترخيصًا.
- استخراج الصفحة يفحص هوية canonical وog:url، ويستخدم محولات BBC والجزيرة وGuardian وCNN أو المحول العام. تُستبعد عناصر التنقل والإعلانات والتعليقات والمقترحات والعناصر المخفية وغير الآمنة، وتتحول الفقرات والعناوين والقوائم والصور إلى عناصر أصلية غير قابلة لتنفيذ HTML أو JavaScript.
- لا يُنفّذ JavaScript ولا تُستخدم ملفات دخول أو محاولات AMP أو مسارات بديلة لتجاوز الاشتراك. الحجب والاشتراك وفشل الهوية والجلب تؤدي إلى مقتطف ورابط أصلي، مع الإبقاء على المحتوى المحفوظ سابقًا.
- تاريخ RSS غير المتاح يُعرض كذلك؛ لا يُختلق تاريخ نشر جديد له.

### عندما لا يتوفر المقال

تظهر العبارة المطلوبة: **«هذا مقتطف من الخبر. يمكنك قراءة التفاصيل الكاملة من المصدر الأصلي»** مع زر **«قراءة الخبر كاملًا»**. يفتح الأصل عبر Chrome Custom Tabs أو متصفح متاح، مع الرجوع إلى نبض. هذا المسار يعمل لكل مصدر لديه رابط أصلي صالح، حتى عند منع الاستخراج أو اعتماد الصفحة على JavaScript.

ظهور حقل محتوى في RSS يعني أنه محتوى نشره المصدر في الخلاصة، وليس ضمانًا مستقلًا بأن الناشر لم يحذف شيئًا من مقاله. لذلك يُسمى «محتوى المصدر المنشور عبر RSS» ويبقى زر الأصل ظاهرًا.

## الصور والعرض

الأولوية: `media:content` ثم `media:thumbnail` ثم enclosure الصوري ثم صور محتوى RSS ثم og:image ثم twitter:image ثم Article.image في JSON-LD، مع الصور الأصلية ضمن جذر المقال. لا تُستخدم صور بحث عشوائية أو صور مولدة.

تُستبعد الشعارات والبيكسلات والصور الصغيرة المعروفة وروابط التنفيذ والبيانات المضمنة. تُحل الروابط النسبية وHTML base وsrcset وحقول التحميل الكسول. الروابط الصورية القديمة ذات HTTP تُطلب لنفس الأصل عبر HTTPS مع التحقق المعتاد من TLS؛ إن لم يدعم المصدر HTTPS تفشل الصورة بأمان، ولا يُسمح باتصال صور غير مشفر.

لا تؤخذ صور Organization أو المقالات الأخرى من JSON-LD. معرّفات `@id` وurl وmainEntityOfPage تُقارن بالخبر، وتُرفض صور المقالات المرتبطة المجهولة المتداخلة. تُدمج نسخ الحجم للصورة الواحدة، بما فيها أنماط BBC وNYT، فلا تتكرر الرئيسية داخل المتن.

شاشة الخبر تتضمن صورة رئيسية بنسبة الملف الأصلية، وعنوانًا كاملًا ومصدرًا وتاريخًا، وفقرات وعناوين وقوائم وصورًا داخلية وتعليقاتها، وتحكمًا بحجم الخط، وحفظًا ومشاركة وتدوينة ورابط الأصل. عند غياب الصورة أو تعذر تنزيلها تظهر بطاقة محايدة، دون صورة بديلة من خبر آخر. مساحة AI والتحليلات منفصلة تمامًا عن النص الأصلي.

Coil يوفر مؤشر تحميل وظهورًا تدريجيًا وتخزينًا في الذاكرة والقرص (حتى 96 MB للصور). لا يُدّعى دعم عرض مراحل JPEG قبل اكتمال فك الترميز. الجلب النصي له cache HTTP مستقل، والتفاصيل الناجحة محفوظة في Room ومهلة مراجعة 24 ساعة، ومحاولات الفشل لها مهلة 30 دقيقة، وrobots cache لمدة 24 ساعة. يمكن طلب إعادة التحقق يدويًا.

## الحفاظ على البيانات والوظائف

`MIGRATION_1_2` يضيف أعمدة فقط، ويملأ summary من النص القديم ويستنتج المصدر عندما يكون الاسم فريدًا. لا تتغير معرّفات الأخبار أو جداول التدوينات والتحليلات والمحادثات والمرفقات والاستخدام. النسخ JSON أصبحت v2 مع استمرار قبول نسخ v1 وإكمال حقولها الناقصة بأمان. المفاتيح والخزنة لم تتغيرا.

الحفظ يعدّل عمود saved فقط، لتفادي محو تفاصيل جُلِبت بالتزامن. OpenAI وGemini وNano يستخدمون `availableText` الأصلي، مع التصريح بحالة المقتطف وحد السياق المرسل؛ لا يُستخدم أي محرك لإكمال المقال. التحليلات القديمة تبقى محفوظة، ومفتاح cache الجديد يمنع خلط نتائج مقتطف قديم بتحليل محتوى جديد.

تم التحقق من تطابق شهادة توقيع APK الجديد مع APK الإصدار السابق المقدم في هذه الجلسة، لذا يمكن تحديثه فوقه دون حذف التطبيق. يبقى هذا توقيع Debug شخصيًا. توقيع Debug الذي ينشئه GitHub Runner جديد قد يختلف؛ يلزم إعداد توقيع ثابت لتحديثات Actions المتكررة، كما يوضح [دليل التوقيع](RELEASE.md).

## الاختبارات والمصادر

ستظهر النتيجة الآلية النهائية وجدول المصادر أدناه. عينات parser التحكمية موجودة داخل ملفات الاختبار فقط ولا تدخل APK أو شاشة الأخبار.

الملفات الصحفية المرجعية نسخ **حقيقية مؤرشفة وقديمة (2015–2019)** من مجموعة اختبارات Mozilla Readability، وليست أخبار اليوم. نُقلت دون تغيير مع SHA-256 ثابت وcommit `ab4027a8b37669745016869a37a504727992b2ba`. تختبر المطابقة مع المتن المرجعي للمصدر أيضًا، ولا تثبت ترخيص الاستخراج الحالي أو استمرار صلاحية روابط الصور على الإنترنت.

الملفات المرجعية تُحمّل باختيار صريح عبر السكربت ولا تُضمّن في APK أو حزمة المصدر؛ manifest وروابطها وتواقيعها موجودة في `scripts/reference-sources.json`. عند غيابها تُوسم اختبارات الأرشيف بأنها غير منفذة بدل استبدالها بنصوص مصطنعة.

### حدود الاختبار الحالي

- محاولات جلب RSS الحي من BBC عربي والجزيرة وGuardian تعذرت بسبب سياسة الشبكة المقيدة في بيئة العمل. سُجلت المصادر الثلاثة `unavailable` مع `URLError`، ولم تُستبدل بعينات أو نتائج نجاح. أداة التصفح لم تقرأ XML أيضًا. لذلك اختبارات RSS الحية الثلاثة غير منفذة، ومنفصلة عن نتائج الأرشيف.
- لم تُنفذ اختبارات واجهة Android أو MigrationTestHelper على جهاز لهذا الإصدار، ولم يُختبر على Samsung Galaxy فعلي. المحاكي البرمجي في الجولة السابقة لم يستقر بسبب Watchdog؛ لا نعد نجاح تجميع حزمة الاختبارات نجاحًا لتشغيلها. اختبار الترحيل المحلي الحالي ينفذ SQL الحقيقي على SQLite ويقارنه بمخططي Room.
- لم يُختبر تحميل بايتات صور المصادر الحية أو فتح Custom Tabs على Galaxy هنا؛ الاختبارات تثبت استخراج الروابط وصلتها بالمتن وترتيبها والفقرات وعدم التكرار. يلزم فحص CDN والحجب وجودة الصور على الهاتف.
- لم تستخدم مفاتيح API حقيقية. اختبارات بروتوكول OpenAI/Gemini المحلية السابقة باقية، ولا يتطلب إصلاح RSS مفتاح AI.

### GitHub Actions

حُدّث `.github/workflows/android.yml` للبناء وLint والاختبارات والـ APK والتقارير، مع تنزيل المرجع المثبت، واختبارات الجهاز على KVM، ووظيفة مستقلة لتدقيق RSS الحي تستعمل **محلل التطبيق نفسه** وترفع نتيجة كل مصدر. تعذر تشغيل Actions عن بعد لعدم وجود مستودع «نبض» متاح أو remote للمشروع، ولم يصل رابط مستودع الهدف. المستودعات المتصلة الأخرى لا تخص هذا التطبيق ولم تُعدّل. لا توجد نتيجة Actions أو رابط تشغيل يُدّعى نجاحه؛ الـ APK المقدم بُني محليًا.

### إعادة الاختبارات

```bash
python3 scripts/fetch_reference_fixtures.py
./gradlew testDebugUnitTest lintDebug assembleDebug assembleDebugAndroidTest
# على جهاز أو محاكي مستقر:
./gradlew connectedDebugAndroidTest
# تدقيق حي صريح، يحتاج شبكة تسمح بالصحف:
python3 scripts/fetch_live_feeds.py
./gradlew testDebugUnitTest --tests 'com.nabd.news.LiveFeedAuditTest' -PliveFeeds=true
```

بعد التثبيت افتح خبرًا محفوظًا أو حدّث الأخبار. إذا لم يُعد المصدر نشره في RSS، يبقى المقتطف والرابط. فعّل جلب الصفحة فقط عند سماح المصدر، ثم استخدم «إعادة التحقق من تفاصيل الخبر». اختبر حفظ الخبر ومشاركته وحجم الخط وصور المتن وفتح الأصل ثم العودة، وتأكد من استمرار الدفتر والتحليلات دون اتصال.
