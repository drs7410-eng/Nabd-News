# نبض المشهد — التنفيذ والتسليم 2.0.0-personal

التاريخ: 2026-10-16. التطبيق الأصلي `com.nabd.news`، versionCode 10، قاعدة Room 7. هذا تطوير داخل المشروع القائم، وليس أداة تشخيص مستقلة.

## ما كان موجودًا وما تغير

فُحصت طبقات الأخبار وقارئ BBC وRoom 6 والتدوينات ومفاتيح AI وميزانية الاستخدام ومشغلات الفيديو والتضمين. أُعيد استخدامها. لم تُستبدل خوارزمية استخراج المقالات أو تُعدّل محددات BBC. يحافظ القارئ على مسار التفاصيل والتحميل وحفظ الموضع الحالي، ويُفتح من تغطيات الموضوع عبر نفس المسار.

أضيف «المشهد» إلى التنقل الرئيسي مع بقاء خمس وجهات. بقي «استكشف» متاحًا بالبحث الشامل من الرئيسية والمشهد ومن الإعدادات. أُبقيت صفحات الفيديو والمفضلة والمصادر ودفتر نبض وإعدادات المحركات. أُضيفت نتائج ملفات المواضيع إلى البحث الشامل.

## الطبقات والبيانات

- `GoogleTrendsDataSource`: RSS رسمي حسب البلد، XML فقط، HTTPS، حد استجابة 4MB، تاريخ المصدر منفصل عن الرصد، مفاتيح ثابتة، ETag وLast-Modified، مهلة إعادة فحص محلية 15 دقيقة، منع تداخل الطلبات للبلد الواحد، حفظ الحالة والأخطاء مع الإبقاء على آخر بيانات سليمة. لا إعادة توجيه إلى نطاق مجهول.
- `NewsClusteringEngine`: تطبيع العربية والأرقام، إزالة التشكيل والتطويل، مقارنة كلمات العناوين موزونة بتكرارها، نافذة 36 ساعة، حواجز للأماكن والتواريخ المعروفة، منع تسلسل التشابه الضعيف. أقصى مدخلات آخر 1000 خبر ضمن 7 أيام. اختلاف الرقم وحده لا يُخفي الروايات؛ الروابط المطابقة فقط تُزال من التجميع. أسماء الأماكن محدودة، وليس استخراج كيانات لغويًا متكاملًا.
- `TrendEngine`: يفصل إشارة البحث عن التغطية المحلية. عدد نطاقات النشر ليس إثباتًا لاستقلال التحرير. التسارع مقارنة أعداد أخبار فعلية في نافذتين، كل منهما ست ساعات، وليس معدل مشاهدات أو نمو بحث محسوبًا.
- `TopicRepository`: مواضيع ثابتة الهوية، تصحيح يدوي للروابط مع استبعاد محفوظ، ملاحظات مرتبطة بالدفتر، حفظ تغير عنوان/تاريخ الخلاصة كحدث رصد مستقل، وليس إثبات تغير المقال نفسه.
- `SharedPostRepository`: إدارة حسابات X وتصنيفات ومجموعات وتفضيلات، حفظ رابط منشور مع نص أدخله/شاركه المستخدم وملاحظته وموضوعه، إزالة معاملات المشاركة ومنع تكرار المنشور ذي الرقم نفسه. لا X API ولا استخراج غير رسمي.
- `TopicAnalysisService`: يعيد استخدام `AiRepository` والمفاتيح المشفرة والميزانية والتسعير وسجل الاستهلاك. يجمع آخر ثمانية أخبار مرتبطة، كاملة إن كانت محفوظة وكاملة، وموسومة كمقتطف عند نقص النص. لا يُقطع متن المقال لتجاوز حد السياق؛ يُرفض السياق الكبير برسالة. لا يجلب المقالات أو يحلل الأخبار تلقائيًا مقابل رسوم.
- `FactCheckCoordinator`: ادعاءات منفصلة، أدلة داعمة/معارضة أو غير مصنفة، روابط وتواريخ وملاحظات الأدلة، نتائج متحفظة. الموقف اليدوي للدليل تصنيف المستخدم، والاستشهاد الآلي يحتاج مراجعة. لا يُمنح حكم بالصحة من كلام النموذج.
- `SceneRefreshWorker`: تحديث اختياري كل ست ساعات وفق جدولة Android الفعلية، شبكة غير محسوبة وبطارية غير منخفضة، تعطيل افتراضي، دون AI أو مراقبة X. تفعيل إبطال Room عبر النسخ لتظهر تغييرات عامل الخلفية عند وجود واجهة مفتوحة.

أضيفت 11 جداول منفصلة: المواضيع، إشارات الاتجاه، روابط الأخبار، الحسابات، المنشورات، روابط التحليلات، الادعاءات، الأدلة، روابط التدوينات، أحداث الخط الزمني، حالة جلب المصادر. الترحيل 6→7 يضيف جداول فقط. بقيت جميع الترحيلات السابقة. لا حذف تدميري لقاعدة المستخدم.

صيغة النسخ الاحتياطي المحلية أصبحت v6 وتضم بيانات الرصد وملاحظاته وارتباطاته. تستقبل v1–v5 بإضافة قوائم رصد فارغة، وتتحقق من الحقول والمعرفات والروابط قبل الكتابة داخل معاملة. تُعاد مطابقة معرفات روابط الأخبار عند دمج نسخة في قاعدة قائمة. المفاتيح وملفات ارتباط X لا تُصدّر. حالات HTTP المؤقتة ليست جزءًا من الأرشيف المستعاد.

## الشاشات

1. الرائج الآن: السعودية أو عينة الأسواق الدولية المتاحة، فترات 24/48 ساعة أو أسبوع، بحث ونوع الإشارة والمتابعة، حفظ سريع، حالة الوصول وإعادة المحاولة، منهجية الحساب وإعدادات الخلفية والمظهر.
2. رصد X: الحسابات والمجموعات والمفضلة والبحث والتضمين الرسمي والمنشورات المحفوظة. استقبال Android Share Intent في التطبيق المفتوح أو عند تشغيله.
3. تغطية الصحف: تجميع محلي من RSS الموجود، عدد نطاقات النشر، روابط مصححة يدويًا، فتح القارئ الحالي.
4. التحليل الذكي: اختيار موضوع ومحرك ومهمة، معاينة نطاق السياق والتكلفة، موافقة صريحة على إرسال نصوص X أو التدوينات، محادثة محفوظة وادعاءات وأدلة.
5. ملف الموضوع: نظرة عامة، خط أحداث بتواريخ ذات دلالة واضحة، تغطيات، X محفوظ، تحليلات، تدوينات. ربط تحليلات وتدوينات سابقة وإنشاء ملاحظات وتطورات يدوية.

نظام بصري مشترك: RTL، ألوان داكنة وفاتحة وهوية كهرمانية وخضراء محدودة، بطاقات 24dp ومسافات 14/20dp، أزرار Material ذات مساحات لمس، حالات تحميل وفراغ وخطأ، LazyColumn ومفاتيح ثابتة، حوارات قابلة للتمرير. لم تُقَس سلاسة S26 Ultra أو الأحجام المكبرة على هاتف فعلي بعد.

## الخدمات وحدودها

مصدر البحث: `https://trends.google.com/trending/rss?geo=SA`؛ الخيارات الدولية في الواجهة عينة الولايات المتحدة والمملكة المتحدة والإمارات، وليست ترتيبًا عالميًا شاملًا. صيغة RSS مدعومة رسميًا في مساعدة Google Trends:
https://support.google.com/trends/answer/3076011

رفض Proxy هذه البيئة الاتصال الفعلي بـGoogle Trends: `Tunnel connection failed: 403 Forbidden`. لم تُثبت بيانات حية ناجحة هنا، ولم يُستبدل الفشل بخلاصة وهمية. الاختبارات المصطنعة مُعلّمة لاختبار البرمجيات فقط. يلزم ضغط «تحديث الرصد» على الجهاز ومراجعة حالة الوصول وعدد الموضوعات الحقيقية.

X يستخدم تضمين `platform.twitter.com/widgets.js` الموجود في مشغل نبض، والوضع الداكن الرسمي. WebView بلا Javascript bridge أو وصول ملفات أو محتوى مختلط، لا قبول لملفات ارتباط طرف ثالث، وإيقاف وتحطيم عند المغادرة. العرض رهين X والشبكة وقيود تسجيل الدخول والحسابات المحمية. لا يعني نجاح عرض إطار HTML نجاح وصول منشورات حقيقية. فتح الأصل إجراء صريح فقط. لا توفر الأداة عدد المشاهدات أو جمع/ترتيب كل المنشورات أو تنبيهات مستقلة عنها. يلزم اختبار تضمين حساب ومنشور عام على الهاتف؛ لم يُعلن نجاحه حيًا.

Google وRSS والتجميع المحلي مجانية ولا تتطلب اشتراكًا جديدًا. OpenAI/Gemini عند اختيارك فقط وبالإعدادات الحالية، دون انتقال تلقائي لمحرك آخر. البحث الخارجي OpenAI اختياري وقد يضيف رسوم أدوات ويُمنع عند وجود ميزانية محلية لا يمكنها حجز تلك الرسوم بدقة. لا بحث حي مضمون في Gemini. Gemini Nano يستخدم المسار المحلي التجريبي؛ العربية غير مدعومة رسميًا في نسخة ML Kit الحالية وجودتها وتوافق الجهاز يحتاجان اختبارًا.

الترتيب محلي شفاف وليس نظام توصيات متعلمًا، والتجميع تقريبي قابل للتصحيح وليس فهمًا مضمونًا لتطابق الأحداث. لا مزامنة سحابية أو إشعارات لحظية لـX. تحليل النصوص المتاحة لا يثبت صحة الادعاءات دون أدلة مستقلة.

## التثبيت والإعداد

خذ نسخة JSON من بياناتك أولًا. ثبّت APK كتحديث فوق نسخة نبض السابقة الموقعة بالمفتاح نفسه، ولا تحذف التطبيق. APK هذا للاستخدام الشخصي Debug، وليس إصدار متجر. إذا ظهر تعارض توقيع توقف ولا تحذف النسخة المحتوية على بياناتك. لا يلزم إدخال مفاتيح موجودة مجددًا. لا ترسل أي مفتاح في المحادثة.

افتح «المشهد» ← «تحديث الرصد». للتجميع حدّث الأخبار الأصلية أولًا؛ يُعاد تجميع الأخبار محليًا عقب تحديثها. أضف حسابًا في «رصد X»، أو من X اختر مشاركة الرابط ← نبض، ثم اربطه بموضوع. لتحليل موضوع اربط الأخبار وافتح «التحليلات»، واضبط المحرك من إعدادات AI الموجودة، ثم راجع السياق والتكلفة واضغط الإرسال.

## قائمة قبول الجالكسي

- تحديث النسخة دون فقد محفوظ أو تدوينة أو مفتاح؛ فتح BBC المرجعي داخل القارئ ثم الرجوع إلى مكان القائمة.
- تحديث Google السعودية ومراجعة HTTP وتاريخ المصدر، ثم فصل الإنترنت وإعادة فتح المحفوظات. القبول الحي يتطلب بيانات حقيقية، وليس مجرد عدم انهيار التطبيق.
- إنشاء/تعديل/حذف حساب ومجموعة وتفضيل، عرض حساب ومنشور عام عبر التضمين. فحص رسالة الحجب/تسجيل الدخول دون طلب كلمة مرور من نبض.
- مشاركة رابط من X إلى نبض باردًا ومفتوحًا، حفظ نص اختياري وملاحظة وربط الموضوع، ثم إعادة التشغيل.
- استبعاد خبر من ملف موضوع وإعادة التجميع والتأكد أنه لم يعد، ومقارنة روايتين متعارضتين دون حذفهما.
- تحليل موضوع بمحرك معد فعليًا، التحقق من نطاق النص المعروض والكلفة، حفظ النتيجة في الدفتر، إعادة الفتح دون إنترنت. لا اتصال AI حقيقي اختُبر بلا مفتاح مستخدم.
- اختبار الوضع الفاتح والداكن وخط 200% والوصول بيد واحدة والأداء مع مئات الأخبار.
- تفعيل/إلغاء خلفية الرصد ومراقبة WorkManager عبر Android؛ الفاصل ليس موعدًا مضمونًا.

الملف `.github/workflows/android.yml` يبني APK الإنتاجي الشخصي ويرفع Artifact باسم `Nabd-Scene-2.0-personal-APK` وتقارير الاختبار، ويشغل اختبارات المحاكي في job مستقل. لا تُضاف مفاتيح API إلى Actions. لم يُشغّل Workflow بعيدًا لأن نسخة العمل هنا لا تحتوي remote لمستودع نبض. يلزم رابط المستودع والفرع لرفع التعديلات وتشغيله فعليًا؛ البناء المحلي ليس تشغيل Actions.

اختبار Google الحي على Android اختياري:
```sh
./gradlew connectedDebugAndroidTest -PbbcDiagnostic=false -Pandroid.testInstrumentationRunnerArguments.class=com.nabd.news.SceneTrendsDeviceTest -Pandroid.testInstrumentationRunnerArguments.sceneLive=true
adb pull /sdcard/Android/data/com.nabd.news/files/scene-trends-live-report.json
```

لا يستدعي هذا الاختبار AI. يُحفظ تقرير HTTP حتى عند فشل الوصول. اختبارات الواجهة المعتادة لا تعلن نجاح الاتصال بالخدمات الخارجية.

نتائج التنفيذ المحلي النهائية وأرقام الاختبارات وبصمة APK مرفقة في `VALIDATION-2.0.json` وملفات سجل البناء ضمن حزمة التسليم، وتفصل الناجح عن المتجاوز أو غير المنفذ.

### حالة مستودع GitHub

طُلب إكمال المستودع، لذلك جُهّز سجل Git محلي وملف `Nabd-Scene-2.0.bundle` للنسخ الكامل، مع `scripts/publish-github.sh` لإنشاء مستودع خاص باسم `Nabd-News` ودفع main وتشغيل Actions عند توفر مصادقة GitHub صالحة. اتصال GitHub المقروء في الجلسة يعرض `drs7410-eng/Resume` فقط ولا يوفّر إنشاء repository جديدًا، و`gh auth status` يرفض الاعتماد الحالي. لا دليل على إنشاء مستودع بعيد أو تشغيل workflow.

على جهاز تطوير مصرح له:
```sh
git clone Nabd-Scene-2.0.bundle Nabd-News
cd Nabd-News
# clone from a bundle installs a local-file origin; remove that local origin only:
git remote remove origin
gh auth login
bash scripts/publish-github.sh
```

المستودع الجديد خاص افتراضيًا. لا تتضمن الحزمة مفاتيح AI أو keystore أو local.properties. مفتاح توقيع Debug الذي تولده Actions قد يختلف عن مفتاح APK المحلي المسلم؛ لتحديثات متوافقة مستقبلًا يلزم إعداد توقيع خاص ثابت في Secrets بشكل منفصل، دون نشره في Git. عند ظهور تعارض توقيع لا تحذف التطبيق وبياناته.

## نتيجة التحقق النهائي المحلي

- بناء مجمد بعد اكتمال جميع تعديلات الشيفرة: BUILD SUCCESSFUL (3 دقائق و31 ثانية).
- 142 اختبارًا: 134 ناجحًا، 8 اختبارات اتصال حي متجاوزة لعدم تفعيلها، صفر فشل وأخطاء. تشمل ثلاث مجموعات رصد: SceneEngineTest (9)، SceneRoomTest (6)، SceneAiIntegrationTest (3)، إضافة إلى اختبار ترحيل SQL 6→7 ضمن المجموعة القائمة.
- Lint: صفر أخطاء و8 تحذيرات. فحص الأمان: 11 فحصًا ناجحًا.
- assembleDebug وassembleDebugAndroidTest ناجحان. تجميع اختبار واجهة لا يعني تنفيذه.
- توقيع APK مطابق للتسليم المحلي السابق. فحص zipalign -P 16 ناجح؛ هذا ليس اختبار توافق Galaxy فعليًا.
- لم ينجح إقلاع المحاكي البرمجي خلال نحو 9 دقائق دون KVM؛ لم تُنفذ اختبارات Compose على جهاز.
- لم يُثبت Google Trends الحي أو تضمين X الحي أو اتصال AI حقيقي أو معايير القبول على Galaxy. هذه نسخة تنفيذ للاختبار، ولا تُعد تلك المعايير معتمدة بمجرد الاختبارات المحلية.
